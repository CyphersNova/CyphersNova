## 👋 Welcome to CyphersNova

We're a collaborative, independent tech community focused on **building, researching, and deploying projects**. Founded in January 2026, primarily by IIT Madras BS in Data Science students, we believe the best way to learn technology is by building real things together.

### 🎯 Our Mission

CyphersNova exists to help students:
- 🛠️ **Build hands-on technical experience** through real project work
- 🤝 **Grow their professional network** with like-minded builders
- 💼 **Increase resume and LinkedIn value** with tangible achievements
- 🧠 **Develop technical and organizational skills** that matter in the real world
- 📚 **Learn by doing** rather than just consuming tutorials

## 🚀 Getting Started

### Step 1: Choose Your Path

We welcome members at all skill levels:

- 🟢 **Beginner-Friendly** - New to coding or the technology? We provide strong mentorship and documentation.
- 🟡 **Intermediate** - Have some programming experience? Perfect for deepening existing skills.
- 🔴 **Advanced** - Ready for complex challenges? Push your limits with specialized projects.

### Step 2: Join a Project

1. **Browse** the [active projects](#-active-projects) above
2. **Read** the project's README and explore the repository
3. **Join** the project's WhatsApp group (link in repo README)
4. **Introduce** yourself to the team
5. **Pick** a good first issue labeled `good-first-issue` or `help-wanted`

### Step 3: Start Contributing

```bash
# Fork the repository
git clone https://github.com/cyphersnova/<project-name>

# Create a new branch
git checkout -b feature/your-feature-name

# Make your changes and commit
git commit -m "Add: brief description of your changes"

# Push and create a pull request
git push origin feature/your-feature-name
```

### Step 4: Stay Consistent

Regular small contributions compound into real progress. We value consistency over perfection!

## 🌟 Community Culture

CyphersNova thrives on collaboration, respect, and a growth mindset. Our core values:

### 📢 Learning in Public
It's okay to not know everything. Ask questions, share your progress, and learn from others openly.

### 🤝 Respectful Collaboration
We value diverse perspectives and constructive feedback. Disagreements are opportunities to learn and grow.

### ✅ Quality over Speed
We prioritize well-documented, thoughtful work over rushing to completion. Take the time to do it right.

## 🛠️ How We Work

### Communication
- **GitHub** - All project work, issues, and pull requests
- **WhatsApp Groups** - Each project has its own group for quick coordination
- **Documentation** - Comprehensive READMEs and wikis in each repository

### Workflow
1. **Issues** - All tasks start as GitHub issues
2. **Branches** - Work on feature branches, never directly on main
3. **Pull Requests** - All changes reviewed by at least one other team member
4. **Documentation** - Update docs with every significant change

### Best Practices
- Write clear commit messages
- Comment your code thoughtfully
- Test your changes before submitting PR
- Respond to review feedback constructively
- Help review others' pull requests

## 🤔 FAQ

<details>
<summary><b>Do I need to be from IIT Madras to join?</b></summary>
<br>
No! While CyphersNova was founded primarily by IIT Madras students, we welcome contributors from anywhere. Our community is independent and open to all motivated learners.
</details>

<details>
<summary><b>What if I'm a complete beginner?</b></summary>
<br>
Perfect! We have beginner-friendly projects and provide mentorship. Start with projects tagged 🟢 and look for issues labeled <code>good-first-issue</code>.
</details>

<details>
<summary><b>How much time should I commit?</b></summary>
<br>
It varies by project and your goals. We value consistency over intensity—even a few hours a week with regular contributions is valuable. Discuss expectations with your project team.

CyphersNova is currently independent of IITM or any other institution. This gives us flexibility to experiment and adapt to our members' needs.
